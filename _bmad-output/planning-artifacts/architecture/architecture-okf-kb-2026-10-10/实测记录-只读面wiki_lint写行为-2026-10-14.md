# 实测记录:只读面 `wiki_lint` 的写行为(2026-10-14)

> 一句话:**`LLM_WIKI_READ_ONLY=1` 只裁掉了写侧工具的注册,保留在"只读面"里的 `wiki_lint` 本身带回写能力**——会写库内报告/元数据,`auto_fix=true` 时还能创建 stub 知识页。此前的"只读 5 个工具"表述需带此边界理解。
> 读者:架构组、安全评审。结论已回写:概要设计 §6.1/§6.2、SPINE AD-3、PRD FR-13/FR-16、addendum §4.1、接入片段、平台查询流程、项目介绍。

## 一、测试环境

- 试验库:`/tmp/okf-verify-lint`(`.llm-wiki`,67 个文件 / 24 页,含 22 个孤儿冒烟页)。
- 服务:只读 HTTP 模式——`WIKI_ROOT=WIKI_HOME=/tmp/okf-verify-lint LLM_WIKI_READ_ONLY=1 LLM_WIKI_HTTP=1`,监听 `127.0.0.1:8905`,`tools/node24/bin/node tools/pi-llm-wiki/mcp-server.mjs`。
- 方法:全库文件 md5 快照,调用前后 `diff` 对比;调用经 curl JSON-RPC(`POST /mcp`)。

## 二、观察(全部为实测,非代码推断)

1. **工具面恰 5 个** ✓:`wiki_recall` / `wiki_search` / `wiki_read` / `wiki_status` / `wiki_lint`。
2. **`wiki_recall` 纯读不写库** ✓:调用前后零文件变化。但返回的 `path` 是**服务端绝对路径**(未裁剪,如 `/tmp/okf-verify-lint/.llm-wiki/wiki/concepts/…md`)——旧文档"裁剪返回中的宿主路径字段"宣称不成立。
3. **`wiki_lint`(默认调用)每次写 2 个文件**:`outputs/lint-<日期>.md`(报告重写)与 `.discoveries/gaps.json`(差距记录重写,带时间戳)。单次调用 diff 实锤。
4. **`wiki_lint(auto_fix=true)` 单次调用写 8 个文件**:追加上述 2 个之外,还有 `meta/events.jsonl`(追加 `kind:"lint"` 事件)、`meta/index.md`、`meta/log.md`、`meta/registry.json`、`wiki/log.md`;并当"缺失页被 ≥2 个页面引用"时**创建 stub 知识页**——实测:给两个冒烟页各加一行 `[[concepts/missing-ghost-test]]` → 调 `auto_fix=true` → `wiki/concepts/missing-ghost-test.md` 落盘,内容 `_Stub auto-created by lint. Expand with content from: …`(frontmatter `status: stub`)。
5. **`auto_fix` 参数对消费方完整暴露**:工具 `inputSchema` 里可见可调(平台侧 LLM 能看到)。
6. **服务启动/重启本身零文件变化**:单独验证(杀进程→快照→起进程→快照,diff 为空)——步骤 3/4 的 `meta/*` 写入由 `auto_fix` 调用触发,不是启动期索引恢复(旧文档"显式跳过启动期索引恢复"宣称不成立,但也无必要)。

## 三、结论与影响

- "只读模式"的准确含义:**11 个写侧/运维工具被物理裁掉**;保留的 `wiki_lint` 是**运维工具、带回写能力**(它不改已有页内容;stub 创建有"≥2 页引用"门槛)。宣传口径应为"5 个工具,其中 4 个纯读 + 1 个运维检查"。
- **不接受任何写行为的场景**(如保密库接平台):须把补丁白名单收窄为 4 个(裁掉 `wiki_lint`)——**该收窄未做,现状 5 个**。是收窄还是接受,留给安全评审定。
- `wiki_recall` 的 `path` 字段暴露 okf-kb 服务器目录结构——内容隔离不受影响,知悉即可。
- 保密库场景的另一层:若 BM 库开给平台,`wiki_lint(auto_fix)` 的 stub 创建会把"被引用的缺失页"变成实际页——内容面被消费方间接写入,安全评审须纳入。

## 四、复现要点

```bash
# 起只读服务(试验库)
WIKI_ROOT=<库> WIKI_HOME=<库> LLM_WIKI_READ_ONLY=1 LLM_WIKI_HTTP=1 \
  LLM_WIKI_HTTP_PORT=8905 LLM_WIKI_HTTP_HOST=127.0.0.1 \
  tools/node24/bin/node tools/pi-llm-wiki/mcp-server.mjs &

# 快照 → 调用 → 快照 → diff
find <库>/.llm-wiki -type f | sort | xargs md5sum > /tmp/before.txt
curl -sS -X POST http://127.0.0.1:8905/mcp -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","method":"tools/call","id":1,"params":{"name":"wiki_lint","arguments":{"auto_fix":true}}}'
find <库>/.llm-wiki -type f | sort | xargs md5sum > /tmp/after.txt
diff /tmp/before.txt /tmp/after.txt
```
