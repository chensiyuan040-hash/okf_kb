# 判断力基线方案(本机产出,内网执行)

> 制定:2026-10-13
> 依据:《验证-复核报告》问题 18 +《手动验证报告-v2》问题 18——**判断可靠性 = 信号存在 × 信号到达 × 信号显著**;强模型读全文能判对,但无结构保证。
> 上游链:《修改计划-复核结论落地》§4(P3)。
> 定位:本方案本机产出,内网(真实库)执行,产出**判断力基线表**。此后换模型、改内容结构后重跑 = 知识库的回归测试。
> 状态:待执行(内网)

---

## 0. 要回答的问题

"AI 哪些能判断?"——把"能判 / 不能判"钉成表格,作为换模型 / 改结构后的回归对照。

## 1. 方法(五步)

1. **克隆真实库**至隔离区(先例 `/tmp/okf-verify/vault`,零污染);
2. **构题**:用真实主题,每个场景 2~3 问——开放式 / 点名式 / 陷阱式(§2);
3. **隔离会话**:只给问题、不预知库内结构,仅凭只读工具自行检索;
4. **双模型对照**:Claude(强) vs 内网目标模型(弱),差集 = 弱模型新增盲区;
5. **观测三点**:调用轨迹(是否 read 全文)/ 结论正确性(对照人工黄金答案)/ 不确定性声明(是否如实声明不确定)。

## 2. 构题规范

每个场景按三问配套(缺一不可,分别测三类能力):

| 题型 | 形式 | 测什么 |
|---|---|---|
| 开放式 | "XX 怎么用?" | 检索可达性 + 组织质量(能否找到并正确综述) |
| 点名式 | "老的 XX 还在吗?" | 替代关系认知(旧页标注是否被读到并提示) |
| 陷阱式 | 问一个 preview 命不中、只有 frontmatter 或正文细节才有的信息 | 是否机械执行 recall→read 全文(防"只凭 preview 作答") |

**场景取材**(每类至少 1 个,建议 4~6 个场景、共 8~18 题):

- **A 替代场景**:库中已被替代的页(真实库首次替代发生前可用克隆库构造),点名式问旧版;
- **B skeleton 场景**:未整理页(Auto-preview 看起来完整),陷阱式问该页细节;
- **C 跨库场景**:personal 库有同主题条目时,问本库内容是否误掺 personal(查 `vaultLabel` 纪律);
- **D 矛盾场景**:两页说法不一致且无标注,看模型是否自行裁断(应声明"库内未标注裁决,请人工确认")。

**黄金答案先行**:每题先由人查库写下正确答案与"应答要点"(该带哪个标注、该不该声明不确定),
作为评估基准,不给模型看。

## 4. 记录模板

### 判断力基线表

| # | 场景 | 题型 | 问题 | Claude:轨迹/结论/声明 | 目标模型:轨迹/结论/声明 | 判定 | 证据摘录 |
|---|---|---|---|---|---|---|---|
| 1 | A 替代 | 点名 | "老的 X 方案还能用吗?" | recall→read,答"已替代,新页为 Y",声明依据 | … | ✅/⚠/❌ | 调用轨迹截图/摘录 |
| … | | | | | | | |

判定口径:

- ✅ 主动带出正确状态(含标注提示)、依据完整;
- ⚠ 答对但未声明依据或未读全文(靠 preview 巧合,换个问法可能就错);
- ❌ 判错 / 漏关键警示 / 自行裁断矛盾。

**盲区清单**(差集):目标模型 ❌/⚠ 而 Claude ✅ 的题逐条记——**缺失的信号环节**(信号不存在 / 未到达(没 read)/ 到达不显著(读了没当回事))。

## 5. 可预填(复核报告问题 18 已证,执行时复核即可)

- 强模型 + read 全文 → 新旧 / 过期判断 ✅;
- 只凭 preview → 靠运气(同题重复问结果不稳);
- 无标注矛盾 → ❌ 不可判(应走流程层人工裁决;模型应声明而非裁断)。

## 6. 回归用法

- 换内网模型 → 重跑本表 → 对照差集变化(回归测试);
- 改内容结构(如调整替代标注规范)→ 重跑 → 验证消费侧判断力不降;
- 基线表落盘(建议与验证文档同目录),作为知识库的"**消费侧回归测试**"资产。
